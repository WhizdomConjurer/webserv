Mandatory HTTP features

The server supports static files, route-specific methods, redirects, autoindex, binary uploads, DELETE, custom error pages, multiple listeners, body-size limits, and non-blocking CGI execution.

The uploaded file can be removed with curl -X DELETE http://127.0.0.1:8080/upload/browser-demo.txt.
